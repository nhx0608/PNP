# PNP repository guidance

The canonical engineering baseline is under `engineering/`. Before changing implementation files, read `engineering/AGENTS.md`, the applicable work package in `engineering/docs/team/`, and any more specific `AGENTS.md` in the target directory.

The root `docs/research/`, `docs/design/proposals/`, baseline documents, and `docs/architecture-review.md` are preserved architecture inputs. They do not override the final contracts and implementation rules in `engineering/docs/spec/`.

Keep research history separate from implementation work. Do not move, replace, or reinterpret historical documents as current executable specifications.
