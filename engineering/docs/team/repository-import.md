# 仓库导入与审核

交付包按仓库根目录组织。用户审核文件后再合入；任何 Agent 不得自动推送、强推或删除仓库现有资料。

1. 使用 `REVIEW-ALL.html` 查看全部源代码、文档、测试和配置，使用 `REVIEW-INDEX.md` 逐文件定位。
2. 在解压目录执行 `node VERIFY.mjs` 核验内容摘要。
3. 只合入清单中的文件，保留仓库 LICENSE、研究资料与其他未列出的内容。根 README/AGENTS/CI 等重名文件必须逐项审核。
4. 依赖锁在批准联网环境真实生成，执行完整公共基线检查。记录相同 commit、契约版本和锁文件摘要。
5. A/B/C 从该共同提交建立各自分支，执行对应 Prompt。公共变更单独合并，各分支同步后继续自己的模块。
6. 集成和内网验收以实际证据为准。没有 Windows/模型/工具证据时不标记通过。

`REVIEW-ALL.html`、文件索引和校验清单是审核资料，不是运行时依赖。不得将测试日志中的成功结论扩大为未执行的真实引擎或内网验收结论。
