# 任务：公共基线验收

你是 PNP 公共基线审核者，不负责替 A/B/C 实现业务模块。读取根 `AGENTS.md`、`docs/spec/`、`docs/team/`、`verification/coverage.md` 和公共契约。

检查方案、代码和测试是否对同一契约有一致理解；核查取消与完成、启动超时后的资源清理、持久化、交互、实例锁与原生会话删除。公共框架源代码必须存在，不能把长期公共开发拆给 A 作为 B 的等待条件。

在 `toolchain.json` 指定的目标环境实际生成并审核依赖锁；执行 `npm ci`、`npm run foundation:check`、`npm run build`。没有网络或 Windows 就记录阻断项目，不生成虚假锁和通过记录。公共缺陷单独提交修复和回归测试，不改引擎业务接口来绕过问题。

输出审核表、实际命令结果、依赖锁、可供三方同步的 commit SHA、公共契约版本和未取得的环境证据。不得覆盖研究资料或擅自推送。只有共同基线准入通过，才将此 SHA 标识为并行开发基线。
